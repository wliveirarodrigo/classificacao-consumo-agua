# 💧 Classificação de Consumo de Água

---

## 📋   Projeto:

Este projeto foi desenvolvido em **Python** com o objetivo de classificar o consumo de água de acordo com o tipo de imóvel e o volume consumido (m³).

O programa solicita ao usuário:

* 🏠 Tipo de imóvel;
* 💧 Consumo água em metros cúbicos (m³).

A partir dessas informações, o programa apresenta uma mensagem de classificação.

---

## ⚙️ Regras do programa

* Tarifa comercial aplicada – consulte o plano corporativo: Se 

| 🏠 Tipo de imóvel   |      💧 Consumo | 📋 Classificação  |
| ------------------- | --------------: | ----------------- |
| 🏢 Comercial        |  Qualquer valor | Tarifa comercial  |
| 🏢 Apartamento      | Menor que 10 m³ | Consumo econômico |
| 🏢 Apartamento      |       Até 25 m³ | Consumo moderado  |
| 🏠 Casa             |       Até 25 m³ | Consumo moderado  |
| 🏠 Casa/Apartamento |  Acima de 25 m³ | Consumo excessivo |
